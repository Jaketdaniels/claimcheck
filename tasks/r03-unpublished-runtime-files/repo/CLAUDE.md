# SectionKit

Open-source quality + taste kit for AI-built Shopify sections & blocks (spec → scaffold → lint → preview).

- Package manager: npm
- Test: `npm test`
- Lint: `npm run lint`

Domain glossary: [CONTEXT.md](CONTEXT.md) · Decision records: [docs/adr/](docs/adr/)

## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues (jessebldr/sectionkit), via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary — the five canonical labels used as-is (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context — one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
